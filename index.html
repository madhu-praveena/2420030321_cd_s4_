03 / CONCEPTS

How the two paths work

01

Interpreter

Lexes and parses the source, then evaluates the Abstract Syntax Tree (AST) directly.

02

Compiler path

Lexes and parses the same source, translates the AST into VM instructions, then executes them.

03

Fair measurement

Each path gets its own lexer/parser pass. Translation is measured only where it exists.
